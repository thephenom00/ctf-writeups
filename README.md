# CTF Writeups
This is my personal archive of all the CTF challenges that I have solved. It is currently a modest collection of the few challenges I completed during my CTU studies, but stay tuned for new ones in the future.

## Why this repo exists
For me, CTF challenges are the best way to improve my skills in offensive security. By expanding this repository, I want to document my progress, explain my approach and demonstrate an understanding of the tools that I use.

## Categories
This repository is organized into folders by CTF category. Each challenge includes a README explaining the solution and screenshots illustrating the process.
